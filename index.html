Olá! Meu nome é Bianca Amaral e este é o meu blog. Aqui vou compartilhar meus estudos, projetos e aprendizados.

Aprendendo HTML

O HTML é utilizado para criar a estrutura das páginas da internet. Com ele podemos adicionar títulos, textos, imagens, links e outros elementos.

Aprendendo CSS

O CSS é responsável pela aparência da página. Podemos modificar cores, tamanhos, espaçamentos, fontes e a disposição dos elementos.

Conhecendo o Flexbox

O Flexbox é uma ferramenta muito importante do CSS. Ele permite organizar os elementos de forma flexível, facilitando a criação de layouts responsivos.

Organizando meu blog

Nesta etapa do projeto, utilizei margem, padding e gap para melhorar o espaçamento entre os cards e deixar o blog mais organizado.

Posts responsivos

Com o uso de flex-wrap e flex, os posts conseguem se adaptar ao tamanho da tela. Quando não há espaço, os cards passam para a próxima linha.
